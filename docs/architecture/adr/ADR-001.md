# ADR-001 — Execução e runtime

**Status:** DECIDED (origem no pacote consolidado aprovado em 2026-11-11; fontes operacionais no índice de documentação e nos módulos/contratos pertinentes).

## Contexto

Aplicação local Linux, web antes de desktop; camada de serviço independente do frontend.

## Decisão

React/TypeScript/Vite, FastAPI Python, worker Python, bind loopback e Tauri incluído na V1 completa.

## Consequências e controles

Node continua necessário às ferramentas de frontend; backend Python exige instalação/empacotamento específico. Testar web local e Tauri/RPM no M7.
