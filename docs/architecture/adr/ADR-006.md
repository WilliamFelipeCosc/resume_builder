# ADR-006 — Provedores de IA

**Status:** DECIDED (consolidado em `PROJECT_SOURCE.md` §§2–13; alterações técnicas aprovadas em 2026-11-11).

## Contexto

Usuário pode operar agentes/modelos distintos e evitar custos inesperados.

## Decisão

Adapter multi-provider; Hermes padrão quando configurado, OpenAI selecionável manualmente; sem fallback automático para API paga; `suggest_answer` opcional no MCP.

## Consequências e controles

Garantir configuração/consentimento, limites e logs de provider sem dados sensíveis; viabilidade de Hermes ainda requer spike.
