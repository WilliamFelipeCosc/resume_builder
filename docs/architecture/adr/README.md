# Registro de decisões arquiteturais (ADR)

Os ADRs 001–015 documentam as decisões `DECIDED` do pacote consolidado de origem, hoje preservadas na documentação modular conforme [ADR-013](ADR-013.md). Documentos históricos detalhados de alguns ADRs **não estavam disponíveis** nesta conversa; estes registros foram redigidos com o contexto e consequências do documento consolidado, sem pretensão de reproduzir atas originais. Os primeiros 13 preservam o escopo preexistente; os ADRs 014/015 foram aprovados posteriormente.

**Regra:** conflito real com decisão aprovada mais recente deve ser registrado, não resolvido silenciosamente. `docs/decisions/open-decisions.md` não é autorização para trocar stack ou escopo.

[ADR-016 — FastMCP independente](ADR-016.md) registra a escolha do framework e o
desenho M0.5 aprovados pelo proprietário em 2026-11-12, preservando os limites dos
ADRs 004/005. O spike `stdio` foi validado com Hermes e Codex; HTTP permanece para M4.
