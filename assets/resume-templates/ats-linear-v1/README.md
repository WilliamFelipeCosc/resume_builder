# ats-linear-v1 — alternativa linear

Template alternativo simples previsto em ADR-015. Em M2 deve ser implementado em componentes React ligados ao mesmo `ResumeDocument` usado pelo visual padrão. Este CSS é um **protótipo de tokens**, não uma interface já implementada.

Características: texto em uma coluna, títulos sem ícones essenciais, ordem lógica de leitura, contatos em texto, lista de experiências com empresa/cargo/período/declarações e educação/skills/idiomas; sem layout de duas colunas. Valide extração real do PDF: não existe pontuação ATS universal nem garantia para todos os parsers.
